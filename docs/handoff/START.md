# 도구별 시작·마무리 문구

사람이 각 도구(Claude Code, Codex, Antigravity)의 새 세션에 붙여 넣는 문구다.

## 시작 문구

```
AGENTS.md와 docs/handoff/STATUS.md를 읽고, STATUS의 '다음 할 일'부터 이어서 진행해. 시작 전에 git status와 git log -5로 상태가 STATUS와 맞는지 확인해.
```

## 마무리 문구

```
지금 단계를 마무리할 수 있으면 마무리하고, 아니면 wip 커밋을 하고 STATUS의 '다음 할 일'에 정확한 위치를 적은 뒤 LOG에 한 줄 남겨.
```
