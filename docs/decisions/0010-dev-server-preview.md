# 0010 — 개발 서버와 로컬 미리보기

> 갱신: 0019 참고 — 자식 프레임의 앱 명령 차단 판단(아래 셋째 문단)은 `http://tauri.localhost:<포트>` 경로를 놓쳤다. 지금의 IPC 격리는 0019가 정한다.

프로젝트 ID, 실제 작업 폴더, 명령이 같은 실행 중 세션은 공유한다. 사용자 설정은 프로젝트에 저장하고, 실행 상태는 기존 ConPTY 세션을 참조하는 앱 수명 메모리에 둔다.

미리보기는 권한을 가진 앱과 다른 출처에서 열며 sandbox로 상위 이동과 팝업을 제한한다. 개발 서버의 원래 출처를 유지해 JavaScript 모듈, 저장소 및 폼을 사용할 수 있다. 앱 자신의 주소는 미리보기 입력에서 거부하고 앱의 응답 헤더로도 프레임 삽입을 차단한다. 원격 Tauri 권한 설정은 없다.

Windows WebView2 개발 창에서 로컬 JavaScript 모듈이 실행되는 것, 부모 문서 접근이 거부되는 것, 자식 프레임의 Tauri 버전 조회가 권한 오류로 끝나는 것을 확인했다. WebView2는 자식에도 Tauri 내부 객체를 만들 수 있으므로 객체 유무가 아닌 실제 명령 권한을 확인했다.

IPv6 주소 리터럴은 프레임 CSP의 호스트 표기 제약 때문에 입력한 주소로 [브라우저로 열기]를 제공한다. 미리보기의 뒤로·앞으로는 주소창으로 연 주소를 추적한다. 프레임 내부 링크나 SPA 라우터 이용은 해당 페이지에서 관리한다.

- [Tauri 기능 권한과 원격 API 접근](https://tauri.app/security/capabilities/)
- [W3C CSP Level 3 출처 목록](https://w3c.github.io/webappsec-csp/)
