# 0009 — 도구 라운드 상한 제거

긴 프로젝트 작업은 모델의 최종 답변, 승인 대기, 사용자 중지 또는 복구할 수 없는 오류까지 진행한다. 기존 요청 시간 제한, 스트림 복구 횟수와 출력 길이 제한에 대한 이어 받기 보호는 유지한다.

활성 턴의 도구 교환으로 모델 요청이 예산을 넘으면 오래된 호출 및 결과를 묶음으로 걷어 내고 최근 요약을 현재 요청에 붙인다. 최소 최근 한 묶음은 유지하고 앱의 원본 실행 기록은 그대로 저장한다. 오래된 결과의 요약은 자료로만 다루도록 표시한다.

모의 LM Studio에서 55회 읽기 뒤 최종 답변에 도달하고, 요청에 남은 각 도구 결과가 호출 ID와 짝을 이루는지 검증한다.

각 실행 결과와 되돌리기 스냅샷은 다음 호출을 시작하기 전에 같은 저장 파일로 기록한다. 끝에서는 같은 스냅샷 ID를 중복 추가하지 않는다. 한 묶음의 도중에 중지가 들어오면 이미 끝난 결과를 남기고 남은 호출을 시작하지 않는다.
