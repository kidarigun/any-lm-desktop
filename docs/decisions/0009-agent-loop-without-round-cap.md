# 0009 — 도구 라운드 상한 제거

상태: 0015로 대체됨 ([0015 — 진행 중 턴 도구 기록 잘라내기 제거, 루프·반복 차단 및 생각 창 자동 스크롤](0015-remove-active-tool-rolling-and-add-loop-guards.md)). 라운드 상한 50회가 복원되었고 진행 중 턴 도구 기록을 잘라 내지 않는다. 아래는 당시 기록이다.

긴 프로젝트 작업은 모델의 최종 답변, 승인 대기, 사용자 중지 또는 복구할 수 없는 오류까지 진행한다. 기존 요청 시간 제한, 스트림 복구 횟수와 출력 길이 제한에 대한 이어 받기 보호는 유지한다.

모델 요청이 예산을 넘으면 완료된 턴의 오래된 도구 호출과 결과를 먼저 줄인다. 현재 턴은 최소 최근 한 호출 묶음을 유지한다. 원본 대화·실행 기록은 앱에 보관하고, 전송 전에 빼낸 최근 결과는 별도의 참고 문맥으로 표시한다.

모의 LM Studio에서 55회 읽기 뒤 최종 답변에 도달하고, 요청에 남은 각 도구 결과가 호출 ID와 짝을 이루는지 검증한다.

각 실행 결과와 되돌리기 스냅샷은 다음 호출을 시작하기 전에 같은 저장 파일로 기록한다. 중간 저장에 성공한 스냅샷은 최종 결과에서 다시 추가하지 않는다. 한 묶음의 도중에 중지가 들어오면 이미 끝난 결과를 남기고 남은 호출을 시작하지 않는다. 프로젝트의 자동 승인 설정은 각 실행 직전에 현재 값으로 확인한다.
