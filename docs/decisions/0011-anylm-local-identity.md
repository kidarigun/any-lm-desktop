# 0011 — Any LM 저장 이름과 기본 카탈로그

- 대화와 프로젝트는 같은 Any LM 앱 데이터 디렉터리의 새 파일 `anylm_desktop_store.json`에 저장한다. 필요하면 이전 Any LM 파일과 백업을 읽고 새 파일을 생성한다. 이전 파일은 복구용으로 보존한다.
- LM Studio 토큰은 같은 Any LM Windows 자격 증명 서비스의 `lm-studio-api-token` 계정에 저장한다. 기존 설치에서만 이전 계정을 읽어 새 이름으로 복사한다. [토큰 삭제]는 두 이름을 모두 정리한다.
- 새 Python 설치 완료 표식, 임시 폴더, ZIP, 문서 번호 매기기와 파일 드래그 식별자는 Any LM 이름을 쓴다. 설치된 런타임은 이전 표식을 인식한다.
- 기본 찾아보기는 내장 MCP 목록을 사용한다. 사용자가 지정한 원격 Skill·MCP 목록, ZIP 설치와 사용 중인 연결은 기존 방식으로 이용한다.
- 원본 출처, 변경 이력, 호환성용 이름과 AGENTS.md가 유지하도록 명시한 내부 명령은 보존한다.
